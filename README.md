# Investment AI

AI-assisted investment analysis project.

## Current scope
- Analyze market data
- Generate buy candidate / sell candidate / watch recommendations
- Explain the reasoning and risks
- Recommendation only: no real-money order execution

## Planned roadmap
1. Market data collection
2. AI analysis
3. Multi-asset analysis
4. Backtesting
5. Paper portfolio

## Setup

```bash
python -m venv .venv
```

Activate the virtual environment, then install dependencies:

```bash
pip install -r requirements.txt
```

Copy `.env.example` to `.env` and add your API key before running the app.
